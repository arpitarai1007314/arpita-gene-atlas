# Arpita Gene Atlas

Create a modern, professional and visually attractive personal portfolio website for a first-year B.Sc. Biotechnology student named Arpita Rai.

Design Requirements:

Use a clean, modern design with a combination of white, navy blue and soft green.

Make the website responsive for mobile, tablet and desktop.

Use smooth scrolling, subtle animations and attractive typography.

Keep the layout simple, professional and easy to navigate.

Website Sections:

Home: Add a welcome message "Hello, I'm Arpita Rai" with a short introduction describing me as a Biotechnology student interested in science, technology, AI and innovation.

About: Introduce me as a first-year B.Sc. Biotechnology student. Mention my interest in biotechnology, scientific research, artificial intelligence and learning new digital skills.

Projects: Create project cards with space for academic and AI-based projects. Include Gene Editing Evidence Atlas as a project, but do not invent achievements or technical details.

Skills: Add Biotechnology, Scientific Research, AI Tools, Digital Literacy, Communication and Basic Data Science as skills.

Contact: Add a simple contact section with a professional message and placeholders for email and LinkedIn. Do not invent contact information.

Additional Requirements:

Add a navigation bar with Home, About, Projects, Skills and Contact.

Ensure all navigation links work correctly.

Add a professional footer.

Use relevant scientific and technology-themed visual elements.

Make the website polished and suitable for a university student portfolio.

Generate the complete working website with all sections properly connected.
